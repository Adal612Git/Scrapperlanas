Arquitectura Militar

Capa Física (Hardware)

🧠 Nodo Central (Debian)

Linux headless optimizado para inferencia IA, sin GUI para máxima RAM disponible.

🛡️ Router CSR106

VLAN 666 - Aislamiento de tráfico, QoS para scraping, Kill Switch automático.

🌐 VPS Gateway

Proxy inverso + WireGuard túnel para proteger IP residencial de bans.

Capa Lógica (Microservicios)

🚀 ingestor-engine

Scraping asíncrono con backoff exponencial, rate limits inteligentes.

🧠 inference-core

Cola Redis + Ollama local, reparación automática de JSON, modelos cuantizados.

⚡ decision-matrix

Fusión de scores, deduplicación semántica, reglas de negocio personalizables.

📨 alert-dispatcher

Telegram con botones de acción, templates inteligentes, historial de alertas.

Persistencia y Datos

🗄️ PostgreSQL

Migración desde SQLite para alta concurrencia y transacciones complejas.

⚡ Redis

Caché distribuida, colas de mensajes, sesiones temporales.

📊 Dashboard

Panel web con métricas en tiempo real, análisis de conversión, reportes automáticos.
